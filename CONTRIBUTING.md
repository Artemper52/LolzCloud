# Разработка LolzCloud

Нужны Node.js 24 LTS, npm и Windows либо Linux. Для Linux также установи [системные зависимости](docs/linux.md).

```sh
npm ci
npm start
```

## Структура

| Путь | Назначение |
| --- | --- |
| `source/main.js` | Окна и жизненный цикл приложения |
| `source/app/` | Интерфейс, стили, мини-плеер и тексты |
| `source/plugins/` | DOM-плагины и обработка звука SoundCloud |
| `source/integrations/lolzteam/` | Привязка аккаунта и музыкальный статус |
| `source/integrations/` | Discord, волна, тексты, скачивание и локальные настройки |
| `source/integrations/windows/` | Индикаторы громкости других приложений Windows |
| `server/` | Вход Lolzteam и комнаты совместного прослушивания |
| `config/app.json` | Публичный Discord Application ID |
| `tests/` | Проверки на вымышленных данных |
| `tools/` | Сборка и проверки |

SoundCloud работает в изолированном webview без Node.js. Ключи остаются в главном процессе; интерфейс получает только публичное состояние. `tools/prepare.cjs` генерирует preload из исходников плагинов перед запуском и сборкой.

## Проверки

```sh
npm run check
npm test
npm run test:audio
npm run test:ui
npm run test:persistence
```

Аудиопроверка использует синтетический сигнал без вывода звука. Проверка интерфейса и два независимых запуска используют отдельные временные профили. Личные аккаунты не нужны. На Linux запускай графические проверки в обычной сессии либо через Xvfb.

Для исправления ошибки добавь проверку её поведения. В PR опиши проблему, результат и выполненные проверки. Не прикладывай cookies, API-ключи, личную историю или содержимое профиля.

## Сборка и релизы

```sh
npm run build
npm run build:linux
```

Закрой запущенную сборку перед перезаписью её папки. Версии в `package.json` и `source/package.json` должны совпадать; `package-lock.json` входит в репозиторий. [Релизный процесс →](docs/github.md)
