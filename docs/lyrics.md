# Тексты и источники

В **Настройках → Источники текста** можно включать сервисы, менять их порядок и добавлять личные ключи. По умолчанию поиск идёт последовательно: Spicy Lyrics → BiniLyrics → Better Lyrics → Musixmatch → Unison → NetEase → LRCLIB → QQ Music → KuGou. Обычный текст появляется сразу, пока продолжается поиск таймингов. Полная пословная версия завершает поиск. Ошибка, отсутствие ключа или лимит одного сервиса не останавливает остальные.

## Общий источник LolzCloud

В «Источниках текста» нажми «Подключить через Lolzteam» и подтверди вход на lolzcloud.com. Серверный ключ Spicy Lyrics общий для пользователей; он находится только на сервере, в исходники и приложение не попадает. Личный ключ вводить не нужно. Общий источник требует входа, ограничивает частоту запросов и хранит ответы сутки; подписи источников и авторов синхронизации сохраняются. Остальные источники доступны без этого входа.

Spicy всё равно нужен Spotify ID именно этой записи: общий ключ даёт доступ к текстам, но не является поиском по SoundCloud. Если соответствие не найдено автоматически, вставь ссылку Spotify в дополнительных настройках текущего текста.

## Личные ключи

- **Spicy Lyrics:** создай клиентский ключ `sl_pk_…` через [панель разработчика](https://developers.spicylyrics.org/). Для нативного клиента включи разрешение запросов без Origin (**No origin header**). Ключ `sl_sk_…` предназначен для серверов; приложение его не принимает. См. [правила ключей](https://developers.spicylyrics.org/docs/keys).
- Spicy Lyrics принимает **Spotify track ID**, а SoundCloud передаёт другие идентификаторы. LolzCloud может найти совпадающую запись через Musixmatch или официальный каталог Spotify с личными Client ID/Secret, указанными в дополнительных настройках. Сверяются название, исполнитель и длительность с допуском 2,5 секунды. Вручную также можно указать ссылку Spotify для текущего трека. Если точного совпадения нет, Spicy пропускается. Данные каталога не нужны для остальных источников.
- **Musixmatch:** добавь свой [ключ разработчика](https://developer.musixmatch.com). Доступ к строкам и richsync зависит от прав этого ключа. Используется официальный API, без чужих токенов приложений или cookies.
- Остальные семь адаптеров не требуют ключей. У сервисов могут быть сетевые и региональные ограничения. BiniLyrics сейчас перенаправляет свой каталог и хранилище в `lrc.red`; адаптер поддерживает это перенаправление.

Ключи шифруются Electron `safeStorage` в `%APPDATA%/LolzCloud/lyric-sources.json`. В SoundCloud, публичный снимок состояния, исходники и архив они не попадают. Пустое поле сохраняет существующий ключ, кнопка **Удалить** удаляет его. Публичное приложение не содержит ключей разработчика.

## Синхронизация

Поддерживаются обычный/enhanced LRC, TTML, NetEase YRC, Musixmatch richsync и формат Spicy Lyrics. Подсветка использует реальные метки строк и слов, в том числе время окончания слова. Обычный текст не получает выдуманных тайм-кодов.

Параметр **Дополнять тайминги** объединяет имеющиеся пословные метки при совпадении полного текста и близких временах начала строк. Разные разбиения текста на строки сопоставляются по последовательности символов. Несовпадающие слова, другая длительность или большой сдвиг не совмещаются. Источники и авторы синхронизации показываются под текстом в обоих плеерах.

Автопрокрутка временно отпускает текст при ручном просмотре и возвращает текущую строку через четыре секунды. Перемотка, изменение темпа и размера окна пересчитывают позицию. Уменьшение анимаций отключает движение и размытие. Личный LRC имеет приоритет над сетевыми результатами.

## Предзагрузка

Текст текущего трека запрашивается сразу после начала воспроизведения, до открытия раздела текста. Два следующих известных трека из волны, плейлиста или доступной очереди SoundCloud прогреваются в фоне. Готовые результаты хранятся в памяти, общий запрос используется основным и мини-плеером. Переключение на уже прогретую запись не запускает поиск заново. При произвольном выборе трека вне очереди может понадобиться загрузка из сети.

Предзагрузка учитывает точный URL записи, исполнителя, название и длительность, не смешивает разные версии. Смена очереди отменяет ненужные фоновые запросы; приватное прослушивание отключает автоматическую предзагрузку.

При нажатии на строку перематывается фактический аудиопоток текущей записи. Подсветка следует подтверждённой позиции звука, поэтому не изображает успешную перемотку, если SoundCloud ещё не готов. В мини-плеере кнопка текста переключает отображение до ответа основного окна и использует уже найденный текст той же записи. При смене трека карточка сохраняется до получения новой информации вместо сброса на приветствие.

## Почему не найден текст или пословные метки

Число прослушиваний в SoundCloud не определяет наличие таймингов в каталогах текста. У одной записи может быть обычный текст, у другой — синхронизация строк, а точные метки слов доступны только там, где источник их предоставляет.

С версии 0.9.1 поиск удаляет рекламные приписки вроде `@tg: …`, обрабатывает названия вида «Исполнитель — Песня», совместные записи через `+`/feat, декоративный Unicode и ё/е. Когда канал перезалива указан как исполнитель, поиск может проверить исполнителей, записанных в заголовке. Сверка по названию, исполнителю и длительности сохраняется: тайминги ремикса, slowed-версии или длинной записи нельзя автоматически назначить короткому отрывку.

В **Текст песни → Источники → Какую песню ищем** отображаются название и исполнитель, использованные для поиска. Их можно поправить; выбор сохраняется для этой записи. Это не изменяет название песни в SoundCloud. Кнопка **Определить автоматически** отменяет ручное уточнение.

Если длительность отличается от каталожной, LRCLIB может предоставить обычный текст с пометкой «Длительность версии отличается». Неподходящие тайм-коды не используются. Временный сбой точного запроса LRCLIB не блокирует поиск по каталогу; неудачная загрузка не кэшируется навсегда.

Доступны несколько источников, включая Better Lyrics, BiniLyrics, LRCLIB и Spicy Lyrics. Better Lyrics запрашивается с названием, исполнителем, подобранным альбомом и длительностью; [его документация](https://docs.betterlyrics.org/) объясняет зависимость бесплатного кэша от этих параметров. Результат может содержать метки слов, строк либо обычный текст.

Для общего Spicy Lyrics нужен вход Lolzteam на сайте, отдельно от привязки API-токена для музыкального статуса. Сам [Spicy Lyrics принимает Spotify ID](https://developers.spicylyrics.org/llms-full.txt); если каталог не может сопоставить запись автоматически, можно указать ссылку на ту же песню Spotify в разделе «Источники». Поля ключей необязательны для остальных доступных источников.

Статусы источников показывают причину отсутствия результата: запись не найдена, другая версия, временная недоступность, лимит или необходимость подключения. Пословная подсветка используется только с настоящими метками слов; она не вычисляется делением строки на равные интервалы.
