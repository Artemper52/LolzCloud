# Linux 0.9.21

Кандидат: x64 AppImage, x64 tar.gz и ARM64 tar.gz. [Отчёт](linux-verification-0.9.21/verification.json).

564/564 Node-тестов прошли без пропусков. Все 155 входных файлов и 13 ресурсов комнаты проверены в трёх пакетах; package.json содержит только допустимые изменения упаковщика, два ZIP помощников — идентичные именованные файлы. Проверены ELF-архитектура и права.

Нативные x64-запуски tar и FUSE AppImage прошли self-test. Настоящий gnome_libsecret выполнил зашифрованный round-trip, renderer sandbox/Seccomp=2 включён. Физический аудиовыход, Wayland, личный вход и ARM64 runtime не проверялись. Проверки независимого тона и сохранения предзагруженного текста описаны в отдельных отчётах.
