# Telegram-бот LolzCloud: результат и проверка

Обновление: пользователь подтвердил отправку аудио. После этого добавлены новый стартовый экран, обложки, карточки и навигация; [актуальный результат оформления](design-2026-11-14.md). Ниже сохранена проверка начального прямого режима.

14 ноября 2026 года, Москва. Бот [@lolzcloudbot](https://t.me/lolzcloudbot) запущен отдельным systemd-сервисом на сервере LolzCloud. Имя определено предоставленным токеном. Настроены логотип проекта, описание и команды.

В любом обычном чате ввести `@lolzcloudbot тёмный принц гной` и выбрать результат. В личке можно написать название, исполнителя или полную HTTPS-ссылку на песню SoundCloud. Бот возвращает выбор песен и отправляет выбранную запись музыкальным аудиофайлом. Добавлять бота в группу для inline-поиска не требуется.

## Что реализовано

- Публичный каталог SoundCloud, 20 результатов на страницу, пагинация, исполнитель и длительность. Заблокированные и preview-записи исключаются. Полная запись преобразуется в MP3 128 кбит/с с названием, исполнителем и встроенной обложкой.
- Постоянный MP3-кэш на сервере, общий для всех пользователей; одинаковые одновременные загрузки объединяются. Поиск кэшируется на 5 минут, Telegram-выдача — на 60 секунд. После перезапуска MP3 сохраняется.
- Полученные при отправке в личку Telegram `file_id` сохраняются для последующих `InlineQueryResultCachedAudio`. Поддержан дополнительный служебный канал для общего Telegram-кэша; **канал пока не настроен**. В личные чаты не отправляются фоновые служебные загрузки.
- Два режима выдачи. Включён прямой audio-режим, который работает и при Inline Feedback 0%. Режим холодных результатов с обложками, как в примере, реализован отдельно: требует Feedback 100% в BotFather и включения `TELEGRAM_INLINE_ARTICLES=1`. Он автоматически заменяет краткий текст загрузки на аудио и оставляет повтор при ошибке. [Telegram: chosen inline result](https://core.telegram.org/bots/api#choseninlineresult).
- В прямом режиме у холодного результата Bot API не имеет отдельного поля обложки; она встроена в MP3. Cached audio использует метаданные и обложку сохранённого Telegram-файла. [Telegram: audio result](https://core.telegram.org/bots/api#inlinequeryresultaudio).
- Безопасные подписанные ссылки аудио, HEAD и byte ranges. Токен бота не входит в ссылки, исходники, отчёты и логи. Два параллельных конвертера и ограниченная очередь, лимиты на запросы и размер кэша. Переписка групп и тексты поисковой истории не сохраняются.

Текущий прямой режим допускает записи до 20 минут и 20 МБ; с отдельным каналом и режимом обложек — до часа и 48 МБ. Треки не обрезаются ради ограничения. Источник может отказать по доступности или региону; нативный SoundCloud OAuth отсутствует, как и в текущем приложении.

## Проверено

| Проверка | Результат |
| --- | --- |
| Общий `npm test` | 275 passed, 0 failed; из них 16 новых Telegram-сценариев |
| Синтаксис JavaScript | 208 файлов; последующие изменения entry point проверены отдельно |
| Серверный поиск «тёмный принц гной» | 20 результатов, точный оригинал первым, 297 мс при первой проверке |

| ID3 и обложка | `гной`, `тёмный принц`; MP3 audio + MJPEG attached picture через настоящий ffprobe |
| Публичный HTTPS | Полный файл совпал по SHA-256, загрузка 461 мс; HEAD 200, range 206, поддельная подпись 404 |
| Telegram API | `getMe`, inline enabled, команды, описание и логотип подтверждены настоящим API |
| Сервис | Active, long polling обновляется; основной backend комнат и профилей 0.9.13 healthy |

Unit-тесты используют настоящий ffmpeg, MP3, локальный HTTP и multipart-форму, а ответы Telegram в них подменены. **Отправка выбранного inline-результата в Telegram UI пока не подтверждена:** установленный клиент в этой среде не авторизован. Пользователю отправлен отдельный запрос на проверку в «Избранном»; личные аккаунты и авторизация не использовались.

Финальный выпуск: `20261113T223709-telegram-eff64637` (имя содержит UTC). Закрытая резервная копия кода/конфигурации находится на сервере. Комнаты обслуживает прежний отдельный процесс; новый маршрут `/telegram/` проксируется на `127.0.0.1:4388`.
