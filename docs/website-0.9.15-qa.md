# Проверка сайта загрузок 0.9.15

Локальный сайт из `website/` проверен 14 ноября 2026 в изолированном Chromium на ширинах 360, 390 и 1440 px. Все 20 проверок прошли. Машинный результат и снимки находятся в [website-0.9.15](./website-0.9.15/).

Проверены главная страница, четыре платформы, кнопки загрузки, установка iOS, оглавление инструкции, переключение скриншотов и увеличение снимка. Горизонтального переполнения нет. Windows, Linux, Legacy и общий архив исходников указывают на 0.9.15, Android — на 0.1.5, iOS — на `/app/`. Нативный проект iOS явно требует Xcode и подпись Apple; опубликованный проверенный IPA не заявлен.

Исправлены два неудобства: рекомендованная платформа перемещается первой в DOM, сохраняя тот же порядок для клавиатуры и экранного чтения; вторичные ссылки загрузок и кнопка в шапке имеют высоту нажатия не меньше 44 px. Основная графика и композиция сайта сохранены.

Фактические снимки 360/390/1440 px и отдельный вариант с iPhone user agent просмотрены. Это проверка локального отображения и целевых адресов ссылок. Наличие опубликованных файлов, подписи, суммы, GitHub Assets и ответы публичного сервера проверяет координатор выпуска отдельно. Страница Linux не означает проверку запуска на физическом Linux; страница iOS не означает проверку Safari или подписанной нативной сборки на устройстве.
