# Платформы LolzCloud 0.9.19

| Клиент | Версия | Подготовленные файлы |
|---|---|---|
| Windows 10/11 x64 | 0.9.19 | Setup.exe, переносимый ZIP |
| Windows 7 SP1 x64 | 0.9.19 Legacy | Отдельные Setup.exe, ZIP и канал обновлений |
| Linux x64 | 0.9.19 | AppImage, tar.gz |
| Linux ARM64 | 0.9.19 | tar.gz; статическая проверка архитектуры и прав |
| Android 8+ | 0.1.9 / код 10 | APK с прежним сертификатом |
| iPhone/iPad | Веб 0.9.22 | Установка Safari → «Поделиться» → «На экран Домой» |
| Нативный iOS/iPadOS | 0.1.4 / сборка 5 | Неподписанный IPA, Simulator ZIP, исходники проекта |

Новые версии сохраняют прежние опубликованные файлы. Метаданные обновлений содержат размер и SHA; подпись Android совпадает с предыдущим выпуском. У Linux проверен настоящий запуск x64, FUSE AppImage, системное хранилище ключей и sandbox. В Windows проверено изолированное обновление 0.9.18 → 0.9.19 с профилем и выбором D при нехватке места на C.

Android-проверки выполнялись на одном APK: волна, настоящий аудиопоток и PCM, каталог, локальное сохранение, переносимый профиль, облако, переходы в комнату и закладки. Наборы перекрываются; их числа не являются количеством независимых пользовательских сценариев. iOS собран Xcode 26.3 / SDK 26.2 и прошёл по 14 runtime-тестов на симуляторах iPhone и iPad. Подпись для распространения Apple отсутствует.

Пределы доказательств и полные отчёты приведены в [описании выпуска](releases/0.9.19.md). Сборка, запуск в симуляторе и доступность файла для загрузки проверяются отдельно. Окончательный статус публикации записывается в отдельную квитанцию после проверки публичных файлов.
