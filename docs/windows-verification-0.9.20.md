# Windows 0.9.20

[Проверенный кандидат](windows-verification-0.9.20/verification.json): современные Windows и сборка Legacy с Electron 22.3.27. Все 155 входных файлов приложения сопоставлены с обоими ASAR; полные наборы содержимого совпали, метаданные упаковщика проверены отдельно.

Шесть файлов выпуска, SHA-256/SHA-512, JSON/YAML обновления и полное покрытие blockmap проверены. Оба упакованных приложения прошли нативный self-test на текущей Windows x64. Настоящая установка 0.9.19 → 0.9.20 выполнена в изолированной тестовой установке: сохранены настройки, коллекции, история, закладки, волна и зашифрованные привязки аккаунтов. Недостаток места и повреждённый установщик отклоняются до изменения приложения.

510 Node-проверок прошли на Windows, 16 тестов Linux пропущены здесь и выполнены отдельно на Linux. Проверка синтаксиса охватывает 303 файла. Аудио и жизненный цикл текста проверены в [отдельном отчёте](lyrics-tempo-cache-0.9.20.md). Физическая Windows 7, личный вход и физический аудиовыход не проверялись. Публикация фиксируется отдельно.
