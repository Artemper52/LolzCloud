## Изменения

Поиск SoundCloud показывает настоящие результаты с обложками внутри приложения. Нажатие запускает MP3 в нативной аудиослужбе, без браузера и WebView. Работают следующие страницы, очередь, предыдущий/следующий трек, перемотка, фон, локальное избранное и история. Скачанный файл сохраняет ту же идентичность, обложку и очередь; новый поиск не заменяет его сетевой ссылкой. Ошибка поиска оставляет музыку играть и предлагает повтор.

Отдельный сервис `/music` на lolzcloud.com предоставляет публичный каталог и MP3-кэш независимо от Telegram-бота и аккаунта Lolzteam. Обычный поиск принимает название/исполнителя или полную ссылку трека SoundCloud. Секреты и account cookies не входят в адрес аудио. Сохранённая подписанная ссылка может восстановить metadata по точному ID при вытеснении старых результатов из памяти сервера.

Вход Lolzteam перенесён на подключение устройства через браузер. Приложение показывает код, получает сессию только после явного подтверждения пользователя, проверяет её через `/api/session`, затем проверяет собственную cookie LolzCloud и возвращается в исходный профиль или комнату. Отмена, устаревший ответ и ошибка проверки откатывают только предварительную cookie этой операции. Новая сессия другого завершённого входа защищена от старых callbacks. [Протокол и ограничения](account-login.md).

Android-обновлятор проверяет официальный манифест сайта и GitHub независимо. Перед системным установщиком проверяются точные размер, SHA-256, package/versionName/versionCode и подпись APK; после возврата из настройки неизвестных источников проверка повторяется. [Контракт](updater.md).

## Установка и границы проверки

Для перехода с 0.1.2 требуется один раз установить APK 0.1.3 **поверх приложения**. Старый APK не знает официальный манифест сайта; эта возможность появляется после установки 0.1.3. Удаление приложения перед обновлением не требуется и потеряет локальные данные.

Сохранена подпись прежней сборки: сертификат SHA-256 `84305e6af2473179b6e124a1822eb82c0343e9bba0b5480cd5a91ecc0dceaa44`. Это существующий development signing, без утверждения о публикации в Google Play. Для последующих обычных обновлений нужен тот же ключ.

Каталог выдаёт доступные полные публичные записи до 20 минут / 20 МБ. Региональные блокировки и закрытые записи не обходятся. Собственного OAuth-приложения SoundCloud нет: личная библиотека, серверные лайки и плейлисты SoundCloud не синхронизируются. YouTube Music остаётся видимым веб-плеером; браузер может понадобиться именно для входа в сервисы. Проверка на эмуляторе не подтверждает все Bluetooth-устройства, звонки и ограничения энергосбережения конкретного телефона.
