# Android 0.1.6: WebView audio и системный Back

Проверен неизменённый APK `LolzCloud-Android-0.1.6.apk`, versionCode **7**, SHA256 `2509087bb8cc80e14675e487093d8f9bbc1a8fb382421142236d9dcd4f6bd17f`. Проверки выполнялись на выделенном `emulator-5554`, Android API 35, `ro.kernel.qemu=1`. APK установлен через `install -r` с сохранением данных. Production-код и опубликованные предыдущие APK во время проверки не изменялись.

- [Room media — 13 проверок, PASS](room-media.json): настоящий Android WebView, два разных HTTPS origin, `HTMLAudioElement`, генерируемый PCM WAV, настоящие `MotionEvent` нажатия. До Join — paused/time 0; нажатие в родителе, задержка и асинхронный fetch запускают аудио дочернего iframe; его время действительно продвигается. Следующий асинхронный трек также запускается. При переходе того же WebView на social production-клиент восстанавливает `mediaPlaybackRequiresUserGesture=true`. Внешних browser intents — 0.
- [Social Back — 17 проверок, PASS](social-back.json): отдельный `--back-only` прогон существующего harness с настоящим bundled `social.js`. Первый системный Back закрывает social drawer и сохраняет Activity, WebView, URL и подключённый room-player DOM; следующий Back выходит обычным способом. Standalone social не зацикливает Back. Общий scope-текст исходного harness шире этой фазы; этот отчёт подтверждает только перечисленные Back-проверки.

Media-test использует явно объявленные `shouldInterceptRequest` HTTPS fixtures. Они не проверяют настоящий SoundCloud/YouTube SDK, членство в комнате, личный вход, TLS удалённого провайдера или слышимое качество звука. `login` в приложении перехватывается нативным входом; этот тест его не открывает. Проверка Back относится к social drawer; новый room-sheet отдельно этим прогоном не подтверждался. Полный набор 71 проверки в этой версии не повторялся.

Исходники: `android/tests/instrumentation/src/com/lolzcloud/mobile/test/RoomMediaInstrumentation.java`, `android/tests/run-room-media.cjs` и существующий `SocialAndroidInstrumentation.java`. Команды: `node android/tests/build-instrumentation.cjs`, `node android/tests/run-room-media.cjs`, `node android/tests/run-social-native.cjs --back-only`. Runner media сверяет установленную версию, код и SHA с production-артефактом. Изменение production `OnlineActivity.java` в этой проверке — room-only media policy; его SHA256: `d0942f47db0bfdf81cfee2842d4ebacb715150400e7d869805e20eabd4153e81`.

После завершения имя AVD, PID и путь процесса были сверены с сохранённой записью запуска; остановлен только собственный LolzCloud AVD. Физические телефоны и личные аккаунты не использовались.
