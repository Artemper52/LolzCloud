# Вход SoundCloud из браузера

При обновлении LolzCloud использует существующий вход: профиль приложения сохраняется, а зашифрованная копия сессии восстанавливается автоматически. Если у новой установки ещё нет входа, приложение проверяет собственные прежние профили LolzCloud/BetterSoundCloud. Намеренный выход из аккаунта не отменяется.

При первом запуске без сохранённого входа открывается выбор аккаунта. Его также можно открыть через **Вход SoundCloud → Войти через браузер** в панели аккаунта и на экране ошибки SoundCloud. Подключённый помощник покажет готовый аккаунт из выбранного профиля браузера: без повторного пароля SoundCloud, экспорта и выбора файла.

## Подключить один раз

1. На странице переноса скачай помощник для Chromium или Firefox и распакуй архив.
2. Chrome, Edge, Opera, Brave, Vivaldi, Яндекс: на странице расширений включи режим разработчика, нажми **Загрузить распакованное** и выбери папку. Firefox: в `about:debugging#/runtime/this-firefox` нажми **Загрузить временное дополнение** и выбери `manifest.json` из отдельного архива Firefox.
3. Обнови страницу переноса. Открой помощник кнопкой браузера, сверь код с окном **Вход SoundCloud** в приложении и нажми **Разрешить автоматический вход**.

После разрешения аккаунт появится отдельной карточкой в LolzCloud. Нажми на него, чтобы войти. Можно открыть ту же передачу в нескольких браузерах и выбрать нужный аккаунт: вход в приложении меняется только после выбора.

Для следующих переносов достаточно кнопки в LolzCloud. На Windows приложение показывает найденные браузеры и их профили: кнопка откроет передачу в выбранном профиле. Название и почта профиля браузера помогают найти нужное окно, но не считаются почтой SoundCloud. Сам аккаунт SoundCloud показывается отдельной карточкой после ответа помощника. Можно также нажать **Скопировать ссылку** и открыть её в любом нужном браузере. Помощник подключается отдельно в каждом профиле. SoundCloud должен быть авторизован в обычном окне этого профиля; закрывать браузер не требуется.

Помощник пока не опубликован в магазинах расширений. Первичная установка требует указанных шагов. Firefox загружает это дополнение временно: после перезапуска Firefox его нужно загрузить снова. Поэтому полностью незаметный перенос из любого произвольного браузера без настройки не обещается.

## Как защищена передача

Приложение сохраняет свой ключ подписи через защищённое хранилище ОС. Помощник запоминает только отпечаток публичного ключа после твоего разрешения. При следующем переносе он проверяет подпись приложения, случайный адрес, ключ шифрования и срок передачи. Другой локальный сайт или другая установка LolzCloud не получают вход автоматически. Отключить привязку можно кнопкой **Отключить автоматический вход** в помощнике.

Помощник читает только разрешённые cookies SoundCloud, включая HttpOnly, и шифрует их AES-256-GCM до передачи. Передача открыта на пять минут и работает только на `127.0.0.1` с проверкой Host и Origin. Предложенные сессии хранятся в памяти до выбора; отмена или истечение срока удаляет их из выбора. Выбранный вход принимается один раз. Сессия не отправляется на сервер LolzCloud, не сохраняется в расширении и не попадает в интерфейс или журналы. Для карточки запрашиваются только имя и публичная ссылка аккаунта SoundCloud. Разрешение на локальную страницу нужно для прямой связи с приложением. История, пароли и сессии других сайтов не читаются. Если защищённое хранилище ОС временно недоступно, приложение не перезаписывает сохранённый ключ; временную привязку потребуется подтвердить заново.

## Запасные варианты

На странице переноса есть закладка **Войти в LolzCloud**: перетащи её на панель закладок, открой SoundCloud и нажми её. Она работает без помощника, если вход доступен JavaScript страницы; защищённые HttpOnly cookies так прочитать нельзя. Закладка относится к текущей пятиминутной передаче.

Помощник также сохраняет зашифрованный файл с выбранным паролем. Для ключа используется PBKDF2-SHA256, 310 000 итераций, случайные salt и IV. LolzCloud принимает этот файл и выбранный пользователем экспорт cookies SoundCloud в JSON или Netscape. Если запись не удалась, приложение пытается восстановить прежний вход.

Перенос входа не устраняет сетевую блокировку SoundCloud. Если сайт доступен только через расширение VPN в браузере, этому расширению недоступен трафик LolzCloud. Проверь системное подключение или VPN для всей Windows. При ошибке приложение показывает экран подключения с повтором и переносом входа.
