# Вход SoundCloud из браузера

В LolzCloud нажми **Вход SoundCloud → Начать перенос в браузере**. Эта кнопка доступна сразу после установки, в панели аккаунта и на экране ошибки SoundCloud.

На открывшейся странице перетащи кнопку **Войти в LolzCloud** в закладки. Открой SoundCloud под своим аккаунтом и нажми эту закладку. Приложение сохранит вход и проверит аккаунт. Пароль SoundCloud вводится только на SoundCloud. При необходимости скопируй ссылку из приложения в Chrome, Edge, Firefox, Opera, Brave или Яндекс Браузер с нужным профилем.

Передача открывается на пять минут. Закладка относится к текущей передаче: для следующей обнови её со страницы переноса. Данные шифруются до перехода на локальный адрес; сетевых запросов с SoundCloud на локальную сеть не требуется. Локальный приёмник работает только на `127.0.0.1`, проверяет адрес и Origin, принимает передачу один раз. Сессия не отправляется на сервер LolzCloud и не показывается в интерфейсе или журналах.

Если браузер не даёт перейти на локальную страницу, на странице переноса есть вторая закладка — **Сохранить вход в файл**. Полученный зашифрованный файл можно выбрать в LolzCloud, пока текущая передача открыта.

Некоторые браузеры защищают cookies флагом HttpOnly: обычная закладка их прочитать не может. На странице переноса доступен исходный код и ZIP помощника браузера. Помощник получает разрешение только на cookies SoundCloud, читает их по нажатию и сохраняет зашифрованный AES-GCM файл с выбранным паролем. Для ключа используется PBKDF2-SHA256, 310 000 итераций, случайные salt и IV. Сетевых запросов, доступа к другим сайтам, истории и паролям у помощника нет.

Для Chromium-браузеров распакованная папка устанавливается через режим разработчика на странице расширений. Firefox позволяет временно загрузить `manifest.json` через `about:debugging#/runtime/this-firefox`; после перезапуска Firefox такое дополнение нужно загрузить снова. Помощник пока не опубликован в магазинах расширений, поэтому первоначальная настройка требует этих шагов.

LolzCloud также принимает выбранный пользователем экспорт cookies SoundCloud в JSON и Netscape. Из него переносятся только разрешённые cookies SoundCloud с действующим входом. Сессии других сайтов, содержимое браузерных баз и пароли не читаются. Если запись cookies не удалась, приложение пытается восстановить прежний вход.

Перенос входа не устраняет сетевую блокировку SoundCloud. Если сайт доступен только через расширение VPN в браузере, этому расширению недоступен трафик LolzCloud. Проверь системное подключение или VPN для всей Windows. Приложение показывает отдельный экран подключения с повтором и переносом входа вместо пустой страницы.
