# LolzCloud 0.9.18: профили между устройствами

Desktop 0.9.18, Android 0.1.8/code9, native iOS 0.1.3/build4 и сервер/PWA 0.9.21 используют существующий формат `lolzcloud-profile` v1. Статус публикации подтверждается отдельным [receipt выпуска](releases/public-0.9.18.json); наличие собранного файла само по себе не означает его публикацию.

Импорт объединяет любимые песни и моменты, сохраняя текущую песню, точное вхождение в очереди и паузу. Настройки звука применяются отдельно, по галочке. Неприменяемые допустимые поля ПК сохраняются для обратного переноса; произвольные неизвестные поля, вход, локальные пути и аудиофайлы в профиль не включаются. Несколько заметок с разными ID на одной позиции сохраняются при обратном экспорте; удаление этой позиции удаляет соответствующие записи. Новый экспорт использует актуальные данные.

Облако хранит зашифрованный конверт v1: scrypt N=16384/r8/p1 и AES-256-GCM. Используется парольная фраза 10–256 UTF-16 символов с исходными UTF-8 байтами без обрезки и нормализации. Пароль не отправляется серверу. Android явно отклоняет одиночные surrogate-коды, чтобы не получить несовместимые ключи. Производные ключи проверены между Node, настоящим браузерным Worker и JVM/Android. Это не заявление о независимом криптографическом аудите.

Сервер возвращает авторитетный `ownerId` вместе с каждой копией и подтверждением записи. Клиенты сверяют владельца, текущую сессию и ревизию. Замена существующей копии требует чтения и отдельного подтверждения. Конфликт 409 не запускает повторную запись. Отмена после уже принятого сервером PUT не обещает откат. Личный OAuth и запись в личный облачный профиль не подменяются успехом изолированных тестов.

Исправлены обнаруженные при независимой проверке дефекты: размер JSON ограничивается и после добавления полей нормализатором; временная смена cookie A→B→A не позволяет принять чужую копию; поздний CORS fallback не возобновляет явно поставленную паузу и не возвращает старую позицию после нового выбора. Для последнего есть 12 отдельных сценариев SoundCloud/YouTube и повторная проверка настоящего плеера.

На ПК появился переносимый preamp −12…0 дБ и полный диапазон скорости 0,5–2×. Настройка −6 дБ проверена на PCM SoundCloud и локального плеера, без изменения пользовательской громкости. В native iOS новые эффекты подтверждаются реальными PCM-кадрами и tagged IPC; старый Native 1.2 продолжает получать прежнюю схему EQ/preamp.

Комнаты используют общий клиент с закреплённым плеером, чатом, очередью и синхронизацией каждые пять секунд. Перенос профиля не меняет общий звук комнаты. Повторная desktop UI-проверка прошла для слушателя и ведущих SoundCloud/YouTube, включая 13 панелей, возвращение и сохранение черновика/аудио. Реализация комнат и прежние исправления описаны в [rooms.md](rooms.md).

Для App Store/TestFlight нужна собственная подпись Apple Developer Program. Для личного теста доступны Mac/Xcode и бесплатный Apple Account с ограниченным сроком подписи; готовая неподписанная IPA напрямую не устанавливается. [Условия Apple](https://developer.apple.com/help/account/basics/about-your-developer-account/). Физические iPhone/Android, внешний DAC, аппаратные уведомления iOS и Linux ARM64 runtime этим выпуском не подтверждены.
