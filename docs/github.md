# Релизы

Официальный репозиторий: [Artemper52/LolzCloud](https://github.com/Artemper52/LolzCloud).

1. Обнови версию в корневом `package.json`, `source/package.json` и lock-файле.
2. Выполни проверки из [CONTRIBUTING.md](../CONTRIBUTING.md).
3. Создай тег `v<версия>` и отправь его на GitHub. Workflow проверит код и подготовит сборки.
4. Проверь артефакты и описание релиза перед публикацией. Названия файлов должны содержать версию, платформу и архитектуру.

Исходники и сборки распространяются вместе с `LICENSE`, `THIRD_PARTY_NOTICES.md` и лицензиями компонентов. Команда `npm run source:zip` создаёт отдельный ZIP исходников без зависимостей, исполняемых файлов и локальных профилей.

Файлы аккаунтов, cookies, `.env`, ключи сервера, логи и папки AppData не входят в репозиторий. Общий Discord Application ID и OAuth Client ID являются публичными идентификаторами; секреты хранятся отдельно.
