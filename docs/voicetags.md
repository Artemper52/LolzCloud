# Voicetag

Короткие звуки загружаются по запросу из публичных источников в папку `voicetags` постоянного профиля. Они не включены в исходный код или Setup. Для использования без интернета нажми «Скачать набор» один раз.

Источники:

- [Тёмный принц — voice tag](https://www.myinstants.com/en/instant/temnyi-prints-voice-tag-intro-85492/)
- [Тёмный принц — ыа ыа](https://www.myinstants.com/en/instant/temnyi-prints-ya-ya-61434/)
- [madk1d — Династия](https://www.myinstants.com/en/instant/madk1d-dinastiiaiaia-59134/)
- [cl6udly — вступление TryToFriend, FORTUNA 812](https://soundcloud.com/fortunasound/fuckyall-prod-cloudly006): сохраняются первые 2,8 секунды с плавным затуханием.

Права на сторонние записи принадлежат их владельцам. Лицензия исходного кода LolzCloud не распространяется на эти записи. Пользовательские звуки конвертируются локально и не отправляются на сервер.
