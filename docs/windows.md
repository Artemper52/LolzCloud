# Установка LolzCloud в Windows

На [lolzcloud.com](https://lolzcloud.com/#download) и в [GitHub Releases](https://github.com/Artemper52/LolzCloud/releases/latest) доступны два варианта.

## Просто: Setup

1. Скачай `LolzCloud-0.9.3-win-x64-Setup.exe` для Windows 10/11 x64.
2. Запусти файл. Приложение установится для текущего пользователя без запроса прав администратора.
3. LolzCloud откроется, а на рабочем столе и в меню «Пуск» появятся ярлыки.

На GitHub открывай раздел **Assets** нужного релиза и выбирай именно файл **Setup.exe**. Установщик скачивается отдельно; исходники для запуска не нужны.

## Вручную: переносимый ZIP

Скачай `LolzCloud-0.9.3-win-x64.zip`, распакуй **всю папку** `LolzCloud-win32-x64` в постоянное место и запусти `LolzCloud.exe`. Не запускай приложение внутри архива и не выноси EXE из папки. При необходимости создай ярлык вручную. Node.js не нужен.

## Windows 7

Используй отдельную экспериментальную сборку **Legacy**: `LolzCloud-0.9.3-win7-legacy-Setup.exe` или `LolzCloud-0.9.3-win7-legacy-x64.zip`. Требуются Windows 7 SP1 x64, рабочие TLS 1.2 и актуальные корневые сертификаты.

Legacy использует Electron 22, последнюю ветку движка с поддержкой Windows 7. Проверка запуска выполнена на современной Windows; реальная Windows 7 пока не проверена. Совместимость SoundCloud и входа через Lolzteam зависит также от веб-сервисов. Поддержка безопасности старого движка завершена. Для Windows 10/11 выбирай обычную сборку.

## Обновление

LolzCloud проверяет новые версии при запуске и затем каждые шесть часов. Когда релиз доступен, появляется кнопка **«Обновиться и перезапустить»**. Она скачивает обновление, проверяет размер и контрольную сумму, сохраняет профиль, устанавливает версию и перезапускает приложение. Можно проверить вручную в настройках.

Установленная версия обновляется через Setup. ZIP-версия обновляет свою отдельную папку; предыдущие файлы остаются в соседней резервной папке. Если папка недоступна для записи, скачай Setup или распакуй новый ZIP вручную. Legacy получает только Legacy-обновления.

Настройки, входы и музыка сохраняются. У Legacy отдельный профиль, чтобы старый движок не менял хранилище обычной версии. Для переноса подборок и вкусов используй «Переносимый профиль» в настройках.

Установщики пока без цифровой подписи: Windows может показать имя неизвестного издателя. Официальные файлы находятся только на сайте и в репозитории Artemper52/LolzCloud; `SHA256SUMS.txt` опубликован рядом с ними.
