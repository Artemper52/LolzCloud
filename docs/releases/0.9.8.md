# LolzCloud 0.9.8

Setup проверяет свободное место для установки и временной распаковки до замены файлов. После копирования он проверяет полноту EXE, пакета приложения и встроенного конвертера. При ошибке установка завершается с кодом ошибки.

Исправлен перенос профиля из прежних версий BetterSoundCloud. Вместе со входом теперь переносятся настройки интерфейса и звука, подборки, история, волна, закладки, локальная библиотека, настройки текстов песен, загрузки, положение мини-плеера и привязка комнат. Пустая папка нового профиля позволяет повторить перенос после прерванного запуска.

Обновления LolzCloud используют постоянную папку профиля. Входы и персональные данные находятся отдельно от файлов приложения. Проверка выпуска включает настоящую установку 0.9.7, обновление через Setup, сравнение файлов и восстановление зашифрованных сессий.

Для Windows 10/11 доступен отдельный Setup.exe с ярлыком на рабочем столе. Переносимый ZIP и экспериментальный Legacy Setup для Windows 7/8/8.1 находятся рядом в Assets.
