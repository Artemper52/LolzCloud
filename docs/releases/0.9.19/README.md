[Квитанция публикации](../public-0.9.19.json) опирается на [проверку зеркала GitHub](mirror-verification.json), [93 публичные проверки](public-downloads.json) и [заключительную проверку метаданных](final-health.json). Все 22 файла (1 075 622 667 байт) прочитаны полностью и сверены по SHA-256 в Actions с официального сайта и после загрузки в GitHub. Дополнительная публичная проверка выполнена по HTTPS с сервера: Windows-проба не прошла из-за сетевого соединения. Исходные ошибки и продолжение проверки сохранены; они не выдаются за успешную Windows-пробу. Проверены оба настоящих обновлятора выпуска 0.9.18: находят 0.9.19 без установки.

Тег и полный архив исходников закреплены за `a98eef6f2ef1403cc621c99fa82ae6398c5ed440`: [1113 файлов Git](source-archive-verification.json) совпали без наложений; [489 Node-тестов и синтаксис 283 файлов](final-source-linux-verification.json) прошли без пропусков. Компилируемые входы Android, Windows/Linux, iOS, PWA и сайта сверены отдельно. Проверки симуляторов и браузерные наборы описаны в [отчёте выпуска](../0.9.19.md); их числа пересекаются.

Этот каталог и квитанция добавлены отдельным коммитом после публикации. Архив, тег и двоичные файлы не менялись. Общий указатель `ios/verification.json` обновлён после записи квитанции отдельной операцией: [ios-published-pointer.json](ios-published-pointer.json). Поле `genericIOSVerificationPointerChanged` в исходной квитанции относится к самой операции её записи. Исторический отчёт 0.1.3 сохранён.

Неподписанный IPA напрямую не устанавливается; [веб-приложение для iPhone/iPad](https://lolzcloud.com/app/) доступно через Safari без Apple Developer.
