# LolzCloud 0.9.18

Любимые песни, моменты и настройки можно перенести файлом между ПК, Android и веб-приложением iPhone/iPad. Для облачной копии используется существующий зашифрованный формат ПК. Импорт показывает предварительный просмотр, объединяет данные и сохраняет резервную копию. Текущая песня и очередь остаются на месте; применение звука подтверждается отдельно.

Android 0.1.8/code9 получает нативный перенос, общий пятиполосный EQ/preamp и разрешение сохранённых SoundCloud-ссылок внутри плеера. Прежние файлы Android поддерживаются для импорта. Копия в облаке проверяет аккаунт и ревизию перед заменой; парольная фраза остаётся на устройстве.

На ПК добавлены preamp −12…0 дБ и скорость 0,5–2×. Поздняя ошибка CORS больше не запускает песню после паузы. Исправлены слишком большие копии после нормализации, потеря нескольких заметок на одной позиции и выдача устаревшего подготовленного файла.

Native iOS 0.1.3/build4 получает настоящее эхо, реверберацию, выравнивание громкости и системное окно отправки профиля. Xcode/SDK-сборки и по 12 runtime-сценариев на iPhone/iPad Simulator прошли. Для установки IPA нужна собственная подпись Apple; бесплатная веб-версия доступна через Safari → «Поделиться» → «На экран Домой».

Windows проверен настоящим обновлением 0.9.17 → 0.9.18. Linux: 445 тестов без пропусков, x64 tar/FUSE/keyring/sandbox и сверка исходников; ARM64 проверен статически. Физические телефоны и личные аккаунты не использовались вместо тестовых окружений.
