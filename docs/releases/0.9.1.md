LolzCloud 0.9.1 — вход из браузера, надёжное переключение назад и поиск текстов.

- На новом ПК предлагается перенос входа SoundCloud из браузера. Сессия передаётся локально в зашифрованном виде; поддерживаются Chrome, Edge, Firefox и другие браузеры с закладками JavaScript.
- Добавлен импорт файлов сессии JSON / Netscape и помощник для защищённых HttpOnly cookies с экспортом в файл с паролем. Первоначальная настройка закладки или помощника описана на странице переноса.
- При ошибке или долгой загрузке SoundCloud отображаются перенос входа, повтор подключения и объяснение отличий браузерного VPN от системного.
- «Предыдущий трек» возвращается к записи из истории, включая быстрые нажатия, мини-плеер, горячие клавиши и Мою волну. Переход назад сохраняет очередь волны и исключения за 24 часа; «Вперёд» возвращает к следующей прослушанной записи.
- Поиск текста очищает рекламные приписки `@tg:…`, распознаёт исполнителей и совместные записи в заголовке, нормализует декоративные символы и ё/е.
- Добавлен Better Lyrics с подбором альбома и длительности; исправлен поиск LRCLIB после сбоя точного запроса. При кратковременной ошибке поиск повторяется позднее.
- Название и исполнителя для поиска можно уточнить в разделе «Источники». Выбор сохраняется для конкретной записи.
- Для укороченных записей возможен обычный текст с явной отметкой об отличии длительности. Пословная подсветка появляется только при наличии настоящих таймингов у источника.

**Windows 10/11 x64:** Setup.exe — простая установка с ярлыком, ZIP — переносимый вариант. В приложении появляется кнопка обновления с установкой и перезапуском.

**Windows 7 SP1 x64 Legacy:** экспериментальная отдельная сборка на Electron 22; на реальной Windows 7 не проверена. **Linux x64/ARM64:** AppImage и tar.gz.
