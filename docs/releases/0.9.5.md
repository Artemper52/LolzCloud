# LolzCloud 0.9.5

Комнаты теперь открываются прямо в главном окне LolzCloud. В каталоге есть открытые комнаты других пользователей, вкладка «Мои», поиск и вход по приглашению. Внутри работают синхронное прослушивание, очередь, чат и реакции. Участники могут зайти в ту же комнату с сайта.

- В боковом меню появились оранжевая кнопка SoundCloud с логотипом и обновлённые иконки. Кнопка «Открыть профиль» выделена отдельно.
- В разделе **Настройки → Интерфейс → Кнопки окна** доступны Windows, macOS и LolzCloud. Полный экран переключается отдельной кнопкой.
- Когда выходит новая версия, в левом верхнем углу появляется кнопка **«Есть обновление»**. Она показывает ход скачивания и запускает установку с перезапуском.
- Исправлено повторное создание комнаты при медленном подключении и после её закрытия с другого устройства.

В разделе Assets есть отдельный **LolzCloud-0.9.5-win-x64-Setup.exe** для Windows 10/11 с ярлыком на рабочем столе и переносимый ZIP. Для Windows 7/8/8.1 доступна экспериментальная Legacy-сборка. Linux доступен в AppImage и tar.gz для x64 и ARM64.
