# LolzCloud 0.9.15-r2: исходники и дополнительная проверка платформ

14 ноября 2026 года. r2 — новая ревизия полного архива исходников и документации. Уже опубликованные настольные бинарные файлы 0.9.15 и Android 0.1.5/code6 остаются прежними. Сервер и PWA имеют отдельную версию 0.9.17; нативные iOS-исходники — 0.1.1.

Ветка `codex/recover-platforms-0.9.15` уже размещена в GitHub. [CI на commit `4def8a9f69c612f7a319f47830bb66d1e8f007b1`](https://github.com/Artemper52/LolzCloud/actions/runs/43617605003) завершился успешно, включая настоящий Apple SDK. Итоговый архив `LolzCloud-0.9.15-r2-source.zip`, native iOS 0.1.1 source archive, tag и GitHub Release на момент этого отчёта ещё ожидают окончательной публикации и проверки. Наличие CI-артефакта не подменяет этот этап.

Веб-ревизия добавляет проверенный импорт собственной музыки и TXT/LRC и исправляет гонку нативного плеера: запоздалый ответ прежнего трека или документа больше не отменяет новый выбор, паузу или возобновление. Нативный и веб-клиент связывают команды через `clientId/requestId`, сохраняя системный Next и конкретный экземпляр повторяющейся записи в очереди. Service worker обновлён до `lolzcloud-app-shell-v3`; [подробности и SHA-256](../ios-pwa-native-intent.md).

В тесте Windows-обновлятора исправлена переносимость фикстуры: Linux `path.dirname` иначе разбирал искусственный Windows executable path. Тест теперь явно проверяет каталоги, переданные в preflight; проверки свободного места, порядка подготовки/установки и восстановления `TEMP/TMP` сохранены. Продуктовый код обновлятора не менялся.

Для Android опубликованный APK сохраняет SHA-256 `ee61577bcf8b45650fad41a76715d3b532012cc949289a61dbb2adfc41db72d0`. Полный 71-check прогон сверил установленный `base.apk` до и после проверки с этой суммой. Настоящий системный picker передал проверенное PNG через production callback; социальные события и вход при этом были изолированными fixtures, без личных аккаунтов.

У Apple SDK CI отдельно проверены вложенные `LolzCloud-iOS-0.1.1-unsigned.ipa` и `LolzCloud-iOS-0.1.1-simulator.zip`: device Mach-O arm64, simulator arm64+x86_64; Info.plist содержит 0.1.1/build2, минимум iOS 16.4, семейства iPhone/iPad и background audio. Сборщик — Xcode 16.4 (16F6), SDK 18.5. У device IPA нет provisioning profile, team или CMS-подписи. Такая сборка не является подписанным приложением для обычной установки на iPhone/iPad. Physical-device audio/lockscreen/interruption/background/file-picker QA и распространение через TestFlight/App Store остаются отдельной работой. Linux ARM64 имеет только статическую проверку архива; macOS desktop GUI/DMG, codesign и notarization не подтверждены.

Общий room-прогон подтвердил 12 сценариев с host и двумя guest-клиентами через настоящие HTTP/SSE: роли, чат, очередь, синхронизация и reconnect. SDK SoundCloud/YouTube были контролируемыми адаптерами. Это три клиента, а не три физических телефона или доказательство одинаковой задержки на разных ОС.

Функции клиентов различаются: личный YouTube Music, расширенный DSP, desktop studio, Discord RPC и forum status доступны не на всех платформах; браузерный фон ограничен ОС. Локальные файлы, любимое, история и закладки не обещают автоматическую межустройственную синхронизацию. Полная [матрица возможностей и ограничений](../platforms-0.9.15.md) сохраняет эти различия. Числа отдельных наборов не суммируются в общий счётчик уникальных пользовательских сценариев.
