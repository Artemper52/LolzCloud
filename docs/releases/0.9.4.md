# LolzCloud 0.9.4

Исправлено управление SoundCloud в основном и мини-плеере, добавлены выбор браузерного аккаунта и скачивание из мини-плеера.

- Пауза, воспроизведение, переключение, громкость и перемотка продолжают работать после загрузки внутренних фреймов SoundCloud. Раньше такая загрузка ошибочно отключала передачу всех команд.
- Нажатие на строку текста перематывает реальный звук, включая аудиообъекты SoundCloud вне DOM. Подсветка следует фактической позиции и больше не показывает мнимую перемотку.
- В мини-плеере у повтора понятные состояния **Повтор / Очередь / Трек**, а у повтора одного трека — значок «1». Добавлена кнопка скачивания текущего трека с состоянием загрузки и открытием готового файла.
- При обновлении сохраняется прежний вход SoundCloud. Своя зашифрованная копия восстанавливается автоматически; при необходимости проверяется собственная прежняя установка. Явный выход из аккаунта сохраняется.
- При первом запуске без входа открывается выбор из браузера. Windows показывает установленные браузеры и имена профилей; помощник передаёт публичную карточку аккаунта SoundCloud. Можно подключить несколько браузеров и выбрать нужный аккаунт, не заменяя текущую сессию до выбора.
- Помощник браузера обновлён до **1.2.0**. Его нужно подключить один раз в каждом профиле; для Firefox есть отдельный архив с временной установкой. Он пока не опубликован в магазинах расширений. Пароли других сайтов не читаются.

Проверены команды при загрузке фреймов, настоящая перемотка в обоих плеерах, скачивание MP3, выбор нескольких аккаунтов, отмена и срок передачи, сохранение сессии и обновление переносимой версии.

- Проверка готового EXE требует явного подтверждения успешного запуска нужной версии движка. Авария рендерера не может завершить проверку с ложным успехом. Windows-сборки проверяются на Windows Server 2022, совместимом со старым движком Legacy.
- Legacy соблюдает режим запроса без cookies при предварительном просмотре предложенного аккаунта.

## Скачать

Windows 10/11 x64: **LolzCloud-0.9.4-win-x64-Setup.exe** — обычная установка с ярлыком и обновлением по кнопке. ZIP — переносимый вариант. Windows 7/8/8.1: отдельные экспериментальные **win7-legacy** Setup и ZIP; на реальной Windows 7 эта версия не проверена. Linux: AppImage и tar.gz для x64/ARM64.

[Установка и выбор аккаунта](https://lolzcloud.com/install.html#browser-sign-in). Перенос входа не заменяет сетевой доступ: VPN только в браузере не распространяется на LolzCloud.
