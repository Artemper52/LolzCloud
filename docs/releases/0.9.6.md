# LolzCloud 0.9.6

Комнаты получили новую сцену с обложкой трека и статусом синхронизации. Чат, реакции и список участников находятся рядом с плеером. На узких экранах чат расположен сразу под сценой.

- Страница подтверждения Lolzteam оформляется и запускает проверку профиля без отдельных файлов оформления и скрипта. При тайм-ауте она показывает, как повторить вход.
- Если ответ после подтверждения подключения потерялся, приложение повторяет запрос и получает ту же сессию. Истёкший код убирается из окна подключения.
- При сбое SoundCloud в комнате продолжают работать чат, реакции и очередь. Звук можно загрузить повторно.
- Уточнены состояния ведущего и слушателя при обрыве связи и передаче пульта.

В GitHub Releases можно отдельно скачать **LolzCloud-0.9.6-win-x64-Setup.exe** для Windows 10/11. Он создаёт ярлык на рабочем столе. В разделе Assets также есть переносимый ZIP, экспериментальная сборка Legacy для Windows 7/8/8.1 и пакеты для Linux x64 и ARM64.
