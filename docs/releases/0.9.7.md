# LolzCloud 0.9.7

В настройках Discord можно отдельно показывать или скрывать профили SoundCloud и Lolzteam. Краткий статус запрашивает название трека. В подробной карточке строка исполнителя содержит только исполнителя.

Интерфейс использует локальный шрифт Inter. Текст разделов увеличен до 14 px, шрифт текста песен обновлён также для Linux. Навигация получила иконки из присланных паков Untitled UI Duotone и Solid.

У волны появился ползунок с подписью уровня новизны. На 100% она исключает знакомые записи, включая распознанные повторные загрузки под другим адресом. Новые треки ищутся через рекомендации любимых исполнителей и похожих записей. Если подходящих записей не осталось, волна сообщает об этом. История повторов сохраняется между запусками.

При появлении Verification Required SoundCloud открывается внутри LolzCloud, чтобы пройти проверку вручную. После её завершения уведомление исчезает.

В сборку входят исправления комнат 0.9.6, в том числе восстановление подключения, повторная загрузка звука и оформление страницы входа.

Отдельный Setup.exe создаёт ярлык на рабочем столе. Переносимый ZIP доступен рядом с установщиком. Для Windows 7/8/8.1 есть экспериментальная Legacy-сборка.
