# LolzCloud 0.9.2

Готовый вход SoundCloud из браузера теперь передаётся прямо в приложение: без файла сессии и отдельного пароля.

- Подключи помощник в нужном браузере один раз и сверь код с LolzCloud. Затем кнопка **Войти через браузер** запускает автоматический перенос, включая HttpOnly cookies.
- Поддержаны Chrome, Edge, Opera, Brave, Vivaldi, Яндекс и Firefox через WebExtensions. Для Firefox поставляется отдельный архив; временную установку нужно повторить после перезапуска браузера. Помощник пока не опубликован в магазинах расширений.
- Привязка узнаёт установку LolzCloud по подписанным запросам и сохраняется после перезапуска приложения. Сессию нельзя автоматически передать другой установке или произвольному локальному сайту. Автоматический вход можно отключить в помощнике.
- Сессия шифруется до передачи, идёт только на этот ПК и не сохраняется в расширении. Экспорт файла и закладка остаются запасными вариантами.
- Проверены первая привязка через интерфейс, прямой перенос HttpOnly, одноразовый приём, повторное подключение, отзыв привязки и отклонение поддельных запросов.

## Скачать

Windows 10/11 x64: **LolzCloud-0.9.2-win-x64-Setup.exe** — обычная установка с ярлыком и кнопкой обновления. ZIP — переносимый вариант. Windows 7/8/8.1: отдельные экспериментальные **win7-legacy** Setup и ZIP. Проверки на реальной Windows 7 пока не было. Linux: AppImage и tar.gz для x64/ARM64.

[Инструкция по входу](https://lolzcloud.com/install.html#browser-sign-in). Перенос сессии не заменяет сетевой доступ к SoundCloud: VPN только в браузере не распространяется на LolzCloud.
