# Проверка обновления 0.9.12 → 0.9.13

Дополнение 14 ноября: после пользовательского сообщения выполнена и настоящая установка. Скачанный Setup был корректен; нехватка места для TEMP на C: давала код 112. Установка с временной папкой процесса на D: завершилась кодом 0. Установленные ASAR и Windows registry подтвердили 0.9.13, все 13 JSON-файлов профиля остались побайтно прежними. [Результат установки](updates-0.9.13-installation.json). Проверки ниже относятся к предшествующему проходу обнаружения обновления.

Проверено 14 ноября 2026 года по Москве. Установленное приложение `D:/Applications/LolzCloud` версии 0.9.12 после одного нажатия «Проверить» показывает: «Доступна версия 0.9.13. Профиль сохранится при обновлении» и кнопку «Обновиться и перезапустить». Кнопка установки не нажималась.

Модули `app-updates.cjs` и `portable-update.cjs` из установленного `app.asar` побайтно совпали с проверенным исходником выпущенной 0.9.12. Этот исходный клиент с `getVersion() = 0.9.12` выполнил живую проверку обоих каналов: GitHub вернул 0.9.12, [официальное зеркало](https://lolzcloud.com/downloads/update.json) — 0.9.13. Клиент выбрал зеркало, вернул `status: available`, `available: true`, `version: 0.9.13`.

Машинный отчёт с контрольными суммами: [updates-0.9.13-verification.json](updates-0.9.13-verification.json). Всего 10 проверок, все PASS. Содержимое Setup и ZIP прочитано с публичного зеркала полностью; файлы не запускались, большие загрузки не сохранялись на диск.

Проверка ограничена обнаружением и целостностью modern Windows x64 обновления. Установка, применение portable-обновления, перезапуск и миграция пользовательского профиля в этом проходе не выполнялись. Сервер, исходный код приложения, аккаунты и параметры профиля не изменялись. Другие платформы и legacy-канал этим проходом не проверялись.
