ANDROID 8.0 И НОВЕЕ

Поставь APK поверх старой версии.

  1. Скачай LolzCloud Android APK.
  2. Открой файл и разреши установку из этого источника, если Android спросит.
  3. Выбери «Обновить». Очередь, сохранённая музыка и настройки остаются в приложении.

В профиле приложения есть проверка обновлений. Подпись APK проверяется перед передачей файла системному установщику.

УСТАНОВКА С САЙТА · БЕЗ СЕРТИФИКАТА

На экране iPhone и iPad.

  1. Открой LolzCloud в Safari.
  2. Нажми «Поделиться» и выбери «На экран Домой». На новых версиях iOS пункт может находиться в меню браузера.
  3. Подтверди добавление и запускай LolzCloud с появившейся иконки.

Это устанавливаемое веб-приложение. Поиск, очередь, плеер, тексты, профили и комнаты работают внутри него. Для офлайн-музыки заранее сохрани нужные треки или импортируй свои MP3, WAV, M4A и FLAC через «Библиотеку». TXT/LRC можно добавить в окне текста песни; поддержка аудиоформата зависит от браузера. iOS может выгружать веб-приложение и очищать его хранилище при нехватке места; поведение фона зависит от версии системы.

НОВОЕ В 0.9.16 · ANDROID 0.1.6

Включай музыку, оставаясь в чате.

В комнате на телефоне плеер закреплён сверху, чат прокручивается отдельно, поле сообщения остаётся внизу.

  1. Нажми «Музыка» рядом с треком и найди песню. Владелец и диджей могут выбрать «Включить сейчас», слушатели — предложить песню.
  2. Открой «Очередь», чтобы увидеть предложения и проголосовать. Ведущий может включить нужную запись сразу.
  3. Закрой панель кнопкой, Esc или «Назад» и продолжай чат. Плеер и черновик сообщения сохраняются. Кнопка приглашения находится у трека.

Управление воспроизведением и перемотка находятся у плеера ведущего. Участники, личная громкость и настройки доступны во вкладке «Комната».

LINUX X64 И ARM64

AppImage или переносимая папка.

  1. Для обычного x64-компьютера скачай AppImage и разреши запуск файла: chmod +x LolzCloud-*.AppImage.
  2. При отсутствии FUSE используй ./LolzCloud-*.AppImage --appimage-extract-and-run или x64 tar.gz.
  3. Для ARM64 скачай ARM64 tar.gz, распакуй всю папку и открой LolzCloud.

Для сохранения входа нужен разблокированный GNOME Keyring или KWallet. Готовое приложение не требует установленного Node.js.

НАТИВНЫЙ КЛИЕНТ · НУЖНА СВОЯ ПОДПИСЬ

Нативная сборка для iPhone и iPad.

Сборка в Xcode прошла. Скачай IPA без подписи, сборку для симулятора или исходники iOS. Неподписанный IPA нельзя установить на iPhone или iPad напрямую: для установки нужна своя подпись Apple. Проверка на физическом устройстве пока не проводилась.

Готовый способ установки без подписи — веб-приложение выше.

САМЫЙ ПРОСТОЙ СПОСОБ

Один файл — готово.

  1. Скачай установщик LolzCloud Setup.exe.
  2. Запусти файл. Установка для текущего пользователя не требует прав администратора.
  3. LolzCloud откроется автоматически. На рабочем столе и в меню «Пуск» появится иконка.

Обычная сборка предназначена для Windows 10 и 11 x64. Для Windows 7 выбери отдельную Legacy-сборку.

РУЧНОЙ ВАРИАНТ

Приложение в своей папке.

  1. Скачай переносимый ZIP.
  2. Распакуй всю папку LolzCloud-win32-x64 в постоянное место.
  3. Открой LolzCloud.exe. Для быстрого доступа создай ярлык вручную.

Не запускай EXE внутри архива и не отделяй его от остальных файлов. Node.js для готового приложения не нужен.

Если скачиваешь с GitHub.

На сайте доступны версии по платформам. В GitHub Releases проверяй номер версии и имя файла: Setup.exe для Windows, APK для Android, AppImage или tar.gz для Linux. iOS устанавливается с сайта; неподписанный нативный проект требует Xcode и подписи Apple.

Открой последний релиз и раскрой Assets. Там отдельно лежат Setup.exe — простая установка — и win-x64.zip для ручного запуска. Это два самостоятельных варианта. Файлы Source code нужны для разработки.

Установщики пока без цифровой подписи; Windows может показать неизвестного издателя. Скачивай файлы с lolzcloud.com или из Artemper52/LolzCloud. Контрольные суммы находятся в SHA256SUMS.txt рядом с файлами релиза.

БРАУЗЕР → LOLZCLOUD

Продолжи со своим аккаунтом.

При обновлении LolzCloud сохраняет прежний вход SoundCloud и автоматически восстанавливает собственную зашифрованную сессию. Если входа ещё нет, первый запуск предложит выбрать аккаунт из браузера. Открыть выбор повторно можно через «Вход SoundCloud» → «Войти через браузер».

  1. Один раз скачай и распакуй помощник для Chrome, Edge и других Chromium-браузеров или отдельный архив Firefox.
  2. В Chromium открой страницу расширений, включи режим разработчика и загрузи распакованную папку. Сохрани её в постоянном месте. В Firefox загрузи manifest.json как временное дополнение через about:debugging#/runtime/this-firefox.
  3. Обнови страницу переноса, нажми значок помощника, сверь код с окном LolzCloud и разреши подключение.
  4. Аккаунт SoundCloud появится карточкой в приложении. Нажми на нужный аккаунт, чтобы войти. Текущая сессия меняется только после выбора.

В Windows LolzCloud показывает найденные браузеры и профили: нажми на нужный, чтобы открыть передачу в нём. Имена и почта профиля относятся к браузеру; аккаунт SoundCloud показывается отдельно после ответа помощника. Можно подключить несколько браузеров в одной передаче и выбрать нужный аккаунт. Также доступна кнопка «Скопировать ссылку».

Поддержаны Chrome, Edge, Opera, Brave, Vivaldi, Яндекс и Firefox. Помощник подключается один раз в каждом нужном профиле и пока не опубликован в магазинах расширений. Firefox загружает дополнение временно: после перезапуска браузера его нужно загрузить снова. Закладка и зашифрованный файл остаются запасными способами.

Сессия шифруется до передачи, включая защищённые HttpOnly cookies, и идёт только на этот ПК. Выбор открыт на пять минут; отмена удаляет предложенные сессии из памяти. Помощник узнаёт подключённую установку по подписанным запросам. Отключить автоматическую передачу можно в его меню.

Если SoundCloud доступен только через VPN-расширение браузера, для приложения требуется системное подключение или VPN для всей Windows. Перенос сессии не меняет сеть.

ИСПРАВЛЕНО В 0.9.15

Комната остаётся с тобой.

Открывай «Звук и эффекты», текст, настройки и библиотеку, сохраняя музыку, роль ведущего и черновик чата. Кнопка «В комнату», крестик и Esc возвращают к комнате. Профиль, поиск и мини-плеер не завершают подключение.

Если перейти в другой раздел во время входа, комната подключится в фоне. В общей комнате используется скорость 1×; эквалайзер и пространственные эффекты основного плеера доступны отдельно. Кнопка «Выйти» освобождает пульт, сохраняя публичную комнату.

Защита от запоздавших ответов плеера сохраняет управление при смене ведущего и переключении SoundCloud/YouTube. Setup использует прежний профиль — входы, настройки и личная музыка сохраняются.

НОВОЕ В 0.9.11

YouTube Music и комнаты.

Исправлен общий плеер YouTube Music при запуске песни с главной или из поиска. В разделе доступны кнопки мини-плеера и текста: пауза, перемотка по строке, повтор, скорость и эквалайзер работают с текущей песней. Voicetag можно включить поверх музыки. Сохранение MP3 из YouTube недоступно.

В карточке песни нажми «Слушать вместе», чтобы включить её всем. Новые комнаты открыты по умолчанию и сразу появляются в общем списке. Переключатели открытости, чата и автоперехода сохраняются сразу. Комнаты поддерживают ссылки SoundCloud и YouTube, поиск SoundCloud и общую очередь. Ведущий управляет основным плеером внутри приложения или плеером в браузере.

После обновления автоматически используются прежние входы SoundCloud, Lolzteam и YouTube Music, привязка комнат, настройки, библиотека, история, закладки и личные тайминги. Повторный вход нужен, только если сервис отозвал сессию.

ИСПРАВЛЕНО В 0.9.9

Установка с проверкой.

Setup заранее проверяет свободное место для установки и распаковки, затем проверяет целостность основных файлов. Если места мало, освободи указанное установщиком количество и повтори установку.

При обновлении используются прежние входы, настройки, история, подборки и закладки. Файлы профиля хранятся отдельно от программы. Выпуск проверяется настоящей установкой и обновлением через Setup.

Открыть каталог комнат ↗

Новая версия? Одна кнопка.

После запуска LolzCloud проверяет обновления, затем повторяет проверку каждые шесть часов. Когда доступна новая версия, слева сверху появляется кнопка «Есть обновление». Нажми её, чтобы скачать и установить обновление. Приложение скачает файл, проверит контрольную сумму, сохранит профиль, установит обновление и перезапустится.

Проверить вручную можно в настройках. Установленная версия использует Setup. ZIP-версия заменяет файлы в своей папке и оставляет предыдущую версию в соседней резервной папке. Папка должна быть доступна для записи. Входы, подборки и музыка сохраняются.

ЭКСПЕРИМЕНТАЛЬНО

Windows 7 SP1 x64.

Выбери Legacy Setup.exe или Legacy ZIP. Для сетевых функций нужны рабочие TLS 1.2 и корневые сертификаты.

Legacy использует Electron 22 — последнюю ветку с поддержкой Windows 7. Её запуск проверен на современной Windows; на реальной Windows 7 пока не проверен. Работа SoundCloud и входа зависит также от доступности веб-сервисов. Поддержка безопасности этого старого движка завершена. Для Windows 10/11 рекомендуем обычную сборку.

У Legacy отдельный канал обновлений и отдельный профиль. Перенести подборки и вкусы можно через «Переносимый профиль» в настройках LolzCloud.
